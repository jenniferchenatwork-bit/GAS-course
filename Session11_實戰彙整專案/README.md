# Session 11：新產品營業額與毛利額彙整系統 (實戰專案)

本專案提供了一套專門用於彙整與分析新產品銷售數據的 Google Apps Script (GAS) 巨集工具。能將每月開發生產的新產品銷售資料從當月營業額工作表（例如 `26'04`）安全、快速且美觀地彙整到 `當月銷售毛利額` 工作表中。

---

## 🌟 核心特色功能

1. **🚀 批次讀寫最佳化 (Batch Processing)**
   - 採用一次性讀取與一次性寫入（`getValues` / `setValues`），大幅減少對 Google API 的呼叫次數，比傳統一列一列寫入快上 **10 倍以上**，完全避開 Google 6分鐘執行逾時限制。

2. **🔍 智慧欄位對照與別名容錯 (Dynamic Column Mapping & Aliases)**
   - 允許來源表與目標表的欄位順序不同。
   - 支援欄位別名系統，例如：`金額` 欄位可自動識別 `營業額`、`銷貨收入`、`銷售額` 或 `Revenue`；`布號` 欄位可自動識別 `品號`、`編號` 或 `Fabric`，不再因為表格微調欄位名稱而報錯。

3. **🧮 缺失數值自動智慧補算 (Smart Calculations)**
   - 若來源工作表缺失部分統計欄位，程式會在記憶體中根據已知欄位自動進行財務計算：
     - **售價** 缺失：以 `金額 / 數量` 補算。
     - **成本價** 缺失：以 `銷售成本 / 數量` 或 `售價 * (1 - 毛利率)` 補算。
     - **銷售成本 (COGS)** 缺失：以 `成本價 * 數量` 或 `金額 * (1 - 毛利率)` 補算。
     - **毛利率** 缺失：以 `(金額 - 銷售成本) / 金額` 補算。

4. **🎨 專業高質感格式設定 (Premium Visual Styling)**
   - 自動將英文與數字欄位字型設為 **Calibri**，中文欄位設為 **Microsoft JhengHei (微軟正黑體)**。
   - 自動套用專業的數值格式設定：金額與銷售成本顯示為 **`$#,##0`** 貨幣格式，售價與成本價顯示為 **`$#,##0.00`**，毛利率顯示為 **`0.0%`**，數量顯示為 **`#,##0`** 千分位。
   - **條件式視覺強化 (Conditional Highlighting)**：自動將**毛利率低於 15%** 的極低毛利品項標示為淡紅色 background 警示，將**毛利率高於 40%** 的高利潤品項標示為淡綠色 background 凸顯，一目了然！

## 🛠️ 安裝與使用指南

### 第一步：複製程式碼
1. 開啟您在 Google 雲端硬碟上的試算表。
2. 點選上方選單的 **「延伸功能」** > **「Apps Script」**。
3. 清除編輯器中原有的所有預設程式碼。
4. 複製並貼上 [code.gs](file:///Users/l.c.jenniferchen/GAS/GAS-course/Session11_%E5%AF%A6%E6%88%B0%E5%BD%99%E6%95%B4%E5%B0%88%E6%A1%88/code.gs) 中的完整程式碼。
5. 點選編輯器上方的 **「儲存 (磁碟圖示)」** 儲存專案。

### 第二步：執行與授權
1. 重新整理（F5）您的 Google 試算表，上方選單右側將會出現一個新選單： **「🚀 新產品彙整工具」**。
2. 點選 **「🚀 新產品彙整工具」** > **「📊 彙整當月新產品資料」**。
3. **首次執行授權**：
   - 系統會跳出「需要授權」提示，請點選 **「繼續」**。
   - 選擇您的 Google 帳號。
   - 點選左下角的 **「進階」** > **「前往『未命名專案』（安全）」**。
   - 點選 **「允許」** 完成授權。

### 第三步：自訂工作表名稱
如果您的來源工作表月份有變動，只需修改 `code.gs` 檔案中最上方的變數即可：
```javascript
var SOURCE_SHEET_NAME = "26'04"; // 例如下個月可修改為 "26'05"
var TARGET_SHEET_NAME = "當月銷售毛利額";
```
